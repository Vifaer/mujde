# Mujde 场景矩阵与早注入对接

文档更新：2026-08-06（v1.2.0）

## 1. 选路矩阵

| 场景 | Mujde 晚注入 | 反 Frida 开关 | Zygisk/Gadget 早注入 |
|------|--------------|---------------|----------------------|
| 普通 hook / 无启动检测 | 足够 | 关 | 不必 |
| SO 较晚加载 | 加大延迟 + `waitModule` | 按需 | 可选 |
| 经典端口/文件名/maps 启发式 | 可能够用 | 开基础档 | 仍更稳 |
| 启动期强反调试 / 商业 RASP | **不够** | 不要指望 | **必须** |
| 需要双重保险 | 绑定脚本 | 可选 | 导出配置后改早注入，并取消 Mujde 绑定防双注 |

## 2. 从 Mujde 导出

首页 → **导出 Zygisk/早注入配置** → 得到 Markdown（含 JSON：包名、脚本名、建议拷贝路径）。

步骤建议：

1. Scripts 导出 zip，或 root 拷贝 `/data/data/com.rel.mujde/files/scripts/`  
2. 按你选用的 ZygiskFrida / Gadget 文档挂载脚本与目标包  
3. 在 Mujde Apps **清空该包勾选**（并移出 scope），避免二次注入  

## 3. strongR 等

**不**随 Mujde APK 分发。若你自备 strongR 等工具，请自行查阅其许可证与文档；本仓库只提供场景指引。

## 4. 与反 Frida 的关系

- Mujde 反 Frida 与用户脚本在 **同一次** `frida-inject` 中按序合并（桥 → bypass → 用户脚本）。  
- 触发点仍是 `Activity.onCreate` 之后，**赶不上**部分启动检测。  
- 启动期对抗请走本节早注入路径。
