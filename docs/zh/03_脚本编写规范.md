# Mujde 脚本编写规范

文档更新：2026-07-31（含本机 Unity / KernelSU 实测）

## 1. 运行时

| 项目 | 值 |
|------|-----|
| 引擎 | Frida（`libfrida-inject.so` via `su -c`） |
| 语言 | Frida JS（GumJS） |
| 可用 | `Process` / `Module` / `Interceptor` / `NativeFunction` / `Memory` / `Java` 等 |
| 不可用 | LSPilot Rhino 专用 API、浏览器 DOM、随意 `require` |

## 2. 必须可重入

每次 `Activity.onCreate` 会再注入。用唯一 `globalThis` 标志：

```js
'use strict';
var FLAG = '__MY_SCRIPT_V1__';
if (globalThis[FLAG]) {
  console.log('[skip] already installed');
} else {
  globalThis[FLAG] = true;
  setImmediate(main);
}
```

## 3. 等待动态库

```js
function waitModule(name, cb) {
  var m = Process.findModuleByName(name);
  if (m) { cb(m); return; }
  setTimeout(function () { waitModule(name, cb); }, 300);
}
```

优先 `setTimeout` 递归；不要假设 `setInterval` 一定存在（LSPilot Rhino 没有）。

## 4. 日志（本机实测）

`console.log` 经 Mujde/`frida-inject` **经常进不了 logcat**。推荐双写 `liblog`：

```js
function alog(msg) {
  var line = '[MYTAG] ' + msg;
  console.log(line);
  try {
    var fn = new NativeFunction(
      Module.findExportByName('liblog.so', '__android_log_write'),
      'int', ['int', 'pointer', 'pointer']
    );
    fn(4, Memory.allocUtf8String('MYTAG'), Memory.allocUtf8String(line));
  } catch (e) {}
}
```

过滤：`adb logcat -s MYTAG:I` 以及 `adb logcat -s "[Mujde]:D"`。

## 5. 短函数禁止 patch（致命）

若目标函数机器码只有几条指令（例如 `ldrb` + `ret` = **8 字节**），**禁止** `Interceptor.replace`，也尽量不要 `attach`：Frida 写跳转会踩坏相邻函数 → `SIGSEGV`（`fault addr 0x11` 一类）。

本游戏 `get_detectCheat` @ `0x6F65C0` 即属此类。应换更大函数做只读观测，或改读字段/其它入口。

验证：

```sh
xxd -s 0x6F65C0 -l 32 /path/to/libil2cpp.so
```

## 6. Unity + Java.perform / Toast（本机致命）

在 `com.zcs.udpmysteryforest` 上实测：`Java.perform` + `Toast` **会导致进程 SIGSEGV**。  
学习/连通性脚本默认 **不要弹 Toast**；用上一节 `liblog`。

其它 App 是否安全需单独验证，勿照搬模板。

## 7. Hook 风格（IL2CPP）

1. Il2CppDumper 取 **arm64 RVA**  
2. `waitModule('libil2cpp.so')`  
3. 优先 `Interceptor.attach`；确认函数足够长再 patch  
4. 实例方法 `args[0]` = this；`long` 返回值用 `retval` / `toInt64()`，不要当成对象指针  

## 8. 文件与命名

| 规则 | 说明 |
|------|------|
| 扩展名 | `.js` |
| 文件名 | ASCII：`mysteryforest_learning_skeleton.js` |
| 编码 | UTF-8 无 BOM |
| 绑定 | Apps UI 勾选；`//Mujde:{packages:...}` 无效 |

## 9. 推荐骨架

见 `scripts/examples/mysteryforest_learning_skeleton.js`（已验证：注入后进程存活 + `MF_LEARN` 日志）。

连通性也可先用 `mujde_hello.js`。

## 10. 不要做的事

- LSPilot `main.java` / Rhino 逻辑原样粘到 Mujde  
- 对 8 字节函数 `replace`/`attach`  
- 在本 Unity 包上用 Toast 当“加载成功”信号  
- 无重入保护地重复 attach  
- 指望文件头自动绑定包名
