# Mujde 脚本存放路径

文档更新：2026-07-31

## 1. 官方运行目录（真正被注入的位置）

```text
/data/data/com.rel.mujde/files/scripts/
```

- 通常需 **Root** 才能直接读写  
- Mujde Scripts 页也读写这里  
- 扩展名建议 `.js`；文件名 ASCII 优先  
- 放入后必须在 **Apps → 目标包 → 勾选**（仅丢文件不会绑定）

### Root 拷贝（KernelSU 已给 shell root 时）

```sh
SRC=/sdcard/Download/frida-modules/mujde/scripts/examples
DST=/data/data/com.rel.mujde/files/scripts
MUJDE_UID=$(stat -c %u /data/data/com.rel.mujde)

mkdir -p "$DST"
cp "$SRC/mysteryforest_learning_skeleton.js" "$DST/"
cp "$SRC/mujde_hello.js" "$DST/"
chmod 644 "$DST"/*.js
chown "$MUJDE_UID:$MUJDE_UID" "$DST"/*.js
# 可选：chcon 与目录内已有文件一致（ls -lZ 对照）
```

或：

```sh
sh /sdcard/Download/frida-modules/mujde/install_scripts.sh
```

## 3. 游戏侧镜像（可选）

```text
/sdcard/Android/media/com.zcs.udpmysteryforest/Analysis/mujde/
```

主副本以 Download/frida-modules/mujde 为准。

## 4. 偏好设置（Root）

```text
/data/misc/apexdata/<GUID>/prefs/com.rel.mujde/mujde_prefs.xml
```

键 `pref_app_scripts_map` 示例：

```json
{"com.zcs.udpmysteryforest":["mysteryforest_learning_skeleton.js"]}
```

查找：

```sh
su -c 'find /data/misc -name mujde_prefs.xml'
```

## 5. 与 APK / 其它模块同级

```text
/sdcard/Download/frida-modules/
├── Mujde-v1.0.0.apk
├── KsuFrida-v1.9.30.zip
├── ZygiskFrida-v1.9.0-release.zip
└── mujde/
```

## 6. 不要放错

| 路径 | 能否被 Mujde 注入 |
|------|-------------------|
| `/data/data/com.rel.mujde/files/scripts/` + Apps 勾选 | ✅ |
| sdcard 暂存 | ❌ 需拷贝并勾选 |
| LSPilot `.../LSPilot/Plugin/` | ❌ 另一套体系 |
| `//Mujde: { packages: [...] }` 文件头 | ❌ 官方不认 |
